# 交接说明（换电脑 / 换 AI 必读）

> 目标：**任何一台新电脑，15 分钟内能跑起来并继续开发**。
> 前提：已安装 Git，能访问 GitHub。

---

## 一、克隆并确认状态

```bash
git clone https://github.com/YANGQINGFEENG/GestureWebController.git
cd GestureWebController
git checkout dev          # 日常开发在 dev，main 保持稳定
git log --oneline -5      # 看一眼最近做了什么
```

然后**先读这两个文件**，再动手：

| 文件 | 为什么读 |
| --- | --- |
| `docs/开发进度.md` | front matter 直接告诉你当前里程碑、下一步做什么 |
| `docs/决策记录.md` | 已定技术方案，别重复讨论或推翻 |

---

## 二、环境

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Python | 3.11 ~ 3.13 | 后端与脚本 |
| Node.js | 20+ | 仅前端构建/SDK 打包时需要，纯静态页面可不装 |
| Git | 2.40+ | — |

```bash
# 后端依赖（M0 开始会有 requirements.txt）
python -m venv .venv
# Windows: .venv\Scripts\activate     macOS/Linux: source .venv/bin/activate
pip install -r backend/requirements.txt

# 前端（M1 开始）
npm install
```

> `.venv/`、`node_modules/` 已在 `.gitignore`，每台机器自己装，不要提交。

## 三、拉模型权重（必做，权重不入库）

```bash
python scripts/download_model.py            # 默认 YOLOv10n，约 22MB
python scripts/check_gesture_map.py         # 校验手势映射与类别是否匹配
```

第二条命令期望输出 `全部手势与模型类别匹配。`；如果报缺类别，说明 `config/gesture_map.json` 与权重不匹配，先看 `docs/决策记录.md` ADR-005。

---

## 四、启动

一条命令起后端 + 演示页（推荐）：

```bash
.venv/Scripts/python scripts/start_dev.py     # Windows
.venv/bin/python scripts/start_dev.py         # macOS / Linux
```

它会打印三个地址：演示页 `http://127.0.0.1:8080/frontend/pages/index.html`、接口文档 `/docs`、健康检查 `/api/health`。

只想单独起后端：

```bash
python -m uvicorn backend.app.main:app --reload --port 8000
```

跑测试（都不需要摄像头、不需要浏览器）：

```bash
node scripts/test_sdk.mjs           # 防抖纯逻辑 9 个用例
node scripts/test_controller.mjs    # 主循环集成 8 个用例（DOM 桩）
python scripts/check_gesture_map.py # 配置里的类别与权重是否匹配
```

## 五、提交前必须做的三件事

1. 更新 `docs/开发进度.md`（front matter + 清单勾选）
2. 追加 `docs/开发日志.md`：`python scripts/log_progress.py "本次做了什么" --next "下一步"`
3. 有技术决策 → 在 `docs/决策记录.md` 加一条 ADR

提交规范：`<type>: <中文说明>`，type 用 `feat` / `fix` / `docs` / `chore` / `refactor`。

`main` 只接受从 `dev` 合入的稳定版本：

```bash
git checkout dev && git merge --ff-only main   # 先同步
git checkout main && git merge --no-ff dev
```

## 六、新机器常见坑（按症状查）

### 推送报证书错误

```
schannel: next InitializeSecurityContext failed: CRYPT_E_NO_REVOCATION_CHECK
# 或
SSL certificate OpenSSL verify result: unable to get local issuer certificate
```

原因：公司/校园网代理导致证书吊销检查失败。**该配置在 `.git/config`，不随仓库同步**，需要每台机器重设一次：

```bash
git config http.sslBackend openssl
git config http.sslVerify false
```

### 22 端口连不上 GitHub

网络封了 SSH 22 端口。用 443：

```bash
git remote set-url origin ssh://git@ssh.github.com:443/YANGQINGFEENG/GestureWebController.git
ssh -T -p 443 git@ssh.github.com    # 应返回 successfully authenticated
```

需要本机有 SSH key 并已加到 GitHub（仓库 Deploy key 需勾选 Allow write access）。

### 没有权重导致启动失败

```
FileNotFoundError: models/YOLOv10n_gestures.pt
```

跑 `python scripts/download_model.py`。

### 摄像头打不开

`getUserMedia` 只在 `https://` 或 `localhost` / `127.0.0.1` 下可用。用 `file://` 直接打开 html 会被浏览器拒绝，起个本地静态服务（`scripts/start_dev.py` 已包含）。

### 没有摄像头怎么开发

这台开发机就没摄像头，不用卡住：

1. 页面点「**用图片序列**」，选几张手势图——每张停留 1.5s，足以攒够 3 帧防抖；
2. 或者「**用本地视频**」，反复回放同一段画面；
3. 验证逻辑本身跑 `node scripts/test_sdk.mjs` 和 `node scripts/test_controller.mjs`，覆盖了触发、冷却、丢帧、多手势取最高分等边界。

但**动作手感（迟滞感、误触发、翻页幅度）最终必须用摄像头验**，这部分挂在 `docs/开发进度.md` 的「待验收」里，别当成已完成。
