## 四、下一步（M1，按顺序执行）

1. **M1-1** `sdk/src/capture.js`：`getUserMedia` 取流、按 6~8fps 抽帧、缩放后 `toBlob` 上传
2. **M1-2** `sdk/src/overlay.js`：Canvas 画框 + 类别 + 置信度
3. **M1-3** `sdk/src/debounce.js`：连续 3 帧同类 + 0.7 阈值 + 800ms 冷却

5. **M1-5** `sdk/src/index.js`：`new GestureWebController({...})` + `on('gestureTrigger')`
6. **M1-6** `frontend/pages/index.html`：摄像头预览 + 控制面板 + 手势列表 + 实时日志 + 长文演示区

> M1 可直接对接真实后端（已就绪），无需 mock。注意摄像头只在 `localhost` / `https` 下可用。
