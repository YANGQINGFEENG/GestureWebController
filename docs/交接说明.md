# 交接说明（换电脑 / 换 AI 必读）

> 目标：**任何一台新电脑，15 分钟内能跑起来并继续开发**。
> 前提：已装 Git、Python 3.11+，能访问 GitHub。

---

## 一、新机器最快起来（3 步）

```bash
# 1. 克隆（认证配不上时先看第二节）
git clone https://github.com/YANGQINGFEENG/GestureWebController.git
cd GestureWebController
git checkout dev              # 日常在 dev 开发，main 是稳定版

# 2. 一键自举：建 venv → 装依赖 → 下权重 → 配置自检 → 起服务
start.bat                     # Windows（双击也行）
./start.sh                    # macOS / Linux

# 3. 打开演示页
#    http://127.0.0.1:8080/frontend/pages/index.html
```

只想先体检、不启动：`start.bat --check`（或 `python scripts/bootstrap.py --check`）。
它会逐项告诉你 venv / 依赖 / 权重 / 配置 / 端口 是否就绪，缺什么补什么。

**动手写代码前先读两个文件**：

| 文件 | 为什么读 |
| --- | --- |
| `docs/开发进度.md` | front matter 直接给出当前里程碑、下一步做什么、有哪些阻塞 |
| `docs/决策记录.md` | 已定的技术方案，别重复讨论或推翻 |

## 二、Git 认证（换电脑第一道坎）

**`.git/config` 里的配置和 SSH 私钥都不随仓库同步**，新机器必须自己配一次，否则 `git push` 会失败。
本仓库之前的真实情况是：22 端口被封、公司/校园网代理导致证书吊销检查失败。

三选一，按你手上有的东西挑：

### 方案 A：HTTPS + 个人访问令牌（最省事，推荐）

```bash
# 1. 到 GitHub → Settings → Developer settings → Personal access tokens → 勾 repo 权限
# 2. 克隆时把 token 当密码
git clone https://<用户名>:<token>@github.com/YANGQINGFEENG/GestureWebController.git

# 3. 遇到证书错误就关掉校验（仅本仓库生效）
git config http.sslBackend openssl
git config http.sslVerify false
```

### 方案 B：新生成 SSH key 并加成 Deploy key

```bash
ssh-keygen -t ed25519 -C "gwc-新机器" -f ~/.ssh/gwc_deploy
cat ~/.ssh/gwc_deploy.pub        # 复制这一行
# GitHub → 仓库 Settings → Deploy keys → Add deploy key → 勾选 Allow write access

# 22 端口不通就走 443
git remote set-url origin ssh://git@ssh.github.com:443/YANGQINGFEENG/GestureWebController.git
ssh -T -p 443 git@ssh.github.com     # 应返回 successfully authenticated
```

### 方案 C：把旧机器的私钥拷过来

旧机器 `~/.ssh/` 下的私钥直接拷到新机器同名位置（权限 `chmod 600`）。
能用，但私钥落在两台机器上，答辩完记得在 GitHub 上删掉这把 deploy key。

## 三、权重怎么拿到新电脑（必做，21.4 MB，不入库）

这一步最容易漏。漏了的表现是后端启动直接 `FileNotFoundError: models/YOLOv10n_gestures.pt`。

```bash
python scripts/download_model.py            # 下载 + 自动校验大小与 sha256
python scripts/download_model.py --verify   # 从别处拷过来后，用它确认没拷坏
python scripts/check_gesture_map.py         # 期望输出：6/6 匹配
```

下载源在俄罗斯的 Sbercloud，国内**多数时候正常**（实测响应 3.5s），但偶发很慢。
实在下不动就从旧电脑拷 `models/YOLOv10n_gestures.pt` 过来（21MB，U 盘/网盘都行），
再用 `--verify` 核对指纹。完整说明见 `models/README.md`。

指纹备查：

```
sha256 = bf628ce3a1638ab19a7ab635c0f674cfec2988989f42f1eef394a6dce5a35b9f
```

## 六、提交前必须做的三件事

1. 更新 `docs/开发进度.md`（front matter + 清单勾选）
2. 追加 `docs/开发日志.md`：`python scripts/log_progress.py "本次做了什么" --next "下一步"`

```bash
git checkout dev && git merge --ff-only main   # 先同步
git checkout main && git merge --no-ff dev
git push origin main dev
```

## 七、常见坑（按症状查）

### 推送报证书错误

```
schannel: next InitializeSecurityContext failed: CRYPT_E_NO_REVOCATION_CHECK
# 或
SSL certificate OpenSSL verify result: unable to get local issuer certificate
```

公司/校园网代理导致证书吊销检查失败。**该配置在 `.git/config`，不随仓库同步**：

```bash
git config http.sslBackend openssl
git config http.sslVerify false
```

### 22 端口连不上 GitHub

见第二节方案 B，走 `ssh.github.com:443`。

### 启动报权重缺失

```
FileNotFoundError: models/YOLOv10n_gestures.pt
```

跑 `python scripts/download_model.py`，或从旧电脑拷（第三节）。

### 访问 127.0.0.1 返回 502（服务明明起来了）

本机设了 `HTTP_PROXY` / `HTTPS_PROXY` 时，`curl` 与 `urllib` 会把本地请求也发给代理，代理不认识 127.0.0.1 就回 502。

```bash
curl --noproxy '*' http://127.0.0.1:8000/api/health    # 命令行绕过
```

脚本里已显式清空代理（`test_api_m*.py`、`check_*.mjs` 都内置），浏览器一般会让 localhost 直连。

### 数据库相关

| 症状 | 原因 / 处理 |
| --- | --- |
| 想清空重来 | 删 `data/app.db`、`-wal`、`-shm` 三个文件，重启即重建并重新种管理员 |
| 登录一直 401 | 多半是删库重建过，旧 token 里 uid 已不存在——清 localStorage 的 `gwc_token` 重新登录 |
| 账号接口 503 | 数据库没起来或被 `GWC_DB_ENABLED=0` 关掉；此时**手势识别照常可用**，只是不落库 |
| `Object is already attached to session` | 两个 Session 之间传了 ORM 对象，约定见 ADR-013：只传 `AuthUser` 快照 |

### 摄像头打不开

`getUserMedia` 只在 `https://` 或 `localhost` / `127.0.0.1` 下可用。`file://` 直接打开 html 会被浏览器拒绝，
起本地静态服务（`start_dev.py` 已包含）。

### 没有摄像头怎么开发 / 答辩

这台开发机从头到尾没有摄像头，替代路径已经跑通并写进自检脚本：

1. 「**用图片序列**」：选 `data/testshots/single/` 里的图，每张停 1.5s，足够攒够 3 帧防抖；
2. 「**用本地视频**」：反复回放同一段画面；
3. 「**用示例图**」/「**手动截屏**」：不依赖任何输入设备验证识别、落盘、入库、截屏；
4. `node scripts/check_embed.mjs`：无头浏览器自动跑一遍嵌入链路。

但**动作手感（迟滞、误触发、翻页幅度）最终必须用摄像头验**，挂在 `docs/开发进度.md` 的「待验收」里，别当已完成。
