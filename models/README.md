# models —— 模型权重目录

模型权重体积较大，**不纳入版本管理**（见根目录 `.gitignore`）。请自行准备后放到本目录：

| 文件 | 用途 | 说明 |
| ---- | ---- | ---- |
| `hand_gesture.pt` | 手势检测（YOLOv8） | 来自开源手势检测仓库的预训练权重 |

## 获取方式

1. 从上游开源 YOLO 手势识别仓库下载预训练权重（`*.pt`）；
2. 放入本目录并重命名为 `hand_gesture.pt`（或在 `config/` 的配置中指定实际文件名）。

## 协议提醒

权重文件遵循上游仓库的开源协议（如 AGPL-3.0），引入时请在本目录或 `docs/` 中登记来源仓库与协议。
